<objective>
**MVP user story (from the ROADMAP Phase 6 Goal + PROJECT.md core value):**
**As a** freelancer running a live engagement, **I want to** advance an engagement into the
ops stage and have the system flag scope creep and overdue invoices as distinct escalation
cards — and stay silent when nothing is wrong — **so that** I catch problems early without
re-reading every client message and invoice by hand.

This plan delivers the DETERMINISTIC (offline, demo-repeatable) ops stage end-to-end: the
three PRD §7.3 dual-use ops tools (D-02), the Stage 2–3 fixture set with creep/clean
variants (D-04/DEMO-01), the `OpsRunner` DI seam (D-03), the enriched typed `OpsSlice` +
`OpsResult` escalation cards (D-06/D-07), and the `POST /engagements/{id}/advance?stage=ops`
branch that completes API-03 (D-05/SC5). The deterministic path is the DEFAULT — it never
touches Bedrock, so every requirement here is provable offline (D-08(b)–(g)).

Purpose: This is the phase's leading vertical slice — the thinnest capture→proposal→ops path
proving the ops wiring before the live unified supervisor (Plan 06-02) is built on top of it.
Output: A working ops stage reachable through `/advance`, with escalation cards that are
conditional (2 on creep, 0 on clean) through one code path.
</objective>
